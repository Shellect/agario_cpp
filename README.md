# Обзор проекта

**Agario** -  это кроссплатформенная многопользовательская игра.

Проект состоит из двух основных компонентов:

- Клиент — приложение на C++ с графическим интерфейсом на базе SFML.
- Сервер — выделенный авторитарный сервер на C++, отвечающий за игровую логику, обработку подключений и синхронизацию состояния.

Игрок управляет клеткой, поглощает более мелкие объекты (еду, других игроков) и растёт, избегая столкновений с более крупными противниками. Сервер полностью контролирует позиции, коллизии и рост, а клиент только отправляет ввод и отображает состояние.

### Сборка и запуск
*Требования*

- Компилятор с поддержкой C++17 (GCC 9+, Clang 10+, MSVC 2019+)
- CMake 3.25.1
- SFML 3.1 (графика, окно, сеть, система)
- PostgreSQL 14+ (для сервера)
- Google Test (для тестов)

*Сборка*
```bash

git clone https://github.com/your-org/agario.git
cd agario
cmake -B build
cmake --build build --parallel
```
